# 🧪 Mes Projets - Laboratoire de Code Personnel

Bienvenue dans mon laboratoire de développement ! Ce dépôt rassemble mes projets personnels, mini-jeux et scripts utilitaires développés en dehors de mes heures de cours. C'est mon espace d'expérimentation pour tester de nouvelles technologies, logique algorithmique et concepts de programmation.

## 🗂️ Organisation du laboratoire

Le dépôt est divisé en plusieurs catégories selon les technologies et les objectifs de développement :

### 🎮 Mini-Jeux (Interface Graphique & Web)
- **Tic-Tac-Toe :** Le grand classique des jeux de réflexion.
- **Jeu de Dames :** Implémentation des règles et de la logique de déplacement des pions.
- **Pixel Art :** Un outil interactif pour créer et dessiner en pixel art.

### 🐍 Utilitaires & Scripts Python
- **Calculateur d'IMC :** Un script rapide pour analyser l'indice de masse corporelle.
- **Testeur de mot de passe :** Un outil de sécurité pour évaluer la force et la robustesse d'un mot de passe.
- **Distributeur automatique :** Simulation algorithmique de la logique d'un automate de vente.

### 📐 Exercices & Algorithmique
- Une collection de mini-programmes et d'exercices pratiques pour affûter ma logique de programmation au quotidien.

## 🛠️ Technologies explorées

- **Langages principales :** Python, JavaScript, HTML5 / CSS3
- **Concepts clés :** Logique algorithmique, manipulation du DOM, interfaces graphiques (GUI), programmation événementielle.

## 🚀 Comment explorer et lancer un projet

Chaque sous-dossier contient son propre script autonome.

### Prérequis
- Python 3.x installé (pour les scripts Python)
- Un navigateur web moderne (pour les jeux JavaScript)

### Lancement d'un script Python (Exemple : Testeur de mot de passe)
1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com
   cd Mes_Projets
   ```
2. **Naviguer dans le dossier du projet et exécuter le script :**
   ```bash
   cd chemin_du_sous_dossier
   python nom_du_script.py
   ```

### Lancement d'un mini-jeu Web
Ouvrez simplement le fichier `index.html` du projet souhaité directement dans votre navigateur internet préféré.
